## 2. 架构分层

```
shared/                    纯 Java 领域逻辑（filter/layout/notice/style/text），15 个测试类
layers/mapping/official/   MC 官方名绑定层：渲染（nvg 子树）、账本、稀有度（30 个源文件）
platforms/1.20.1-forge/    Forge 胶水：入口、配置、TOML、harness、语言资源
versions/*.json + gradle/pickupcard-layers.gradle   层装配唯一声明，CI 第一道闸校验
```

- **无分层违例**：本轮新加的 `rarity/LinkedRarity.java`（接口，纯 Java）放在 layers，
  Forge 依赖的 `compat/RarityCoreBridge.java`（ModList/反射）放在 platform——与
  `CardStage.setSources` 同款交接面。CI 无 RarityCore jar 也能构建（反射不引编译期依赖）。
- **待办（记入 backlog）**：`docs/architecture.md` 未记 rarity 联动桥与 compat 包，下轮文档顺路补。
