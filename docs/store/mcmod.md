[h1=概述]

拾卡（Pickup Card）在你捡起物品或经验时弹出一张卡：物品图标、名字、本次进账数量，稀有度决定强调色 —— 捡东西不再只有「叮」一声和物品栏里多出来的一格；

纯客户端模组：服务端不用装，任何服务器与任何整合包都能用，零必需前置；

卡面全部由 NanoVG 矢量自绘，不依赖原版提示纹理，也不依赖任何渲染前置。

[h2=功能]

🃏 卡片提示 — 拾取物品或经验时弹出一张卡：竖条（稀有度色）+ 物品图标 + 名字 + 数量；

➕ 合并 — 连捡同一样东西并进同一张卡（四档可选），数字弹一下往上滚，不刷屏；

🔇 过滤三表 — 黑名单（不弹）、白名单（永远弹并强调）、静音名单（弹，但不强调）；规则支持 minecraft:stone / #forge:ores / @somebotania 三种写法，内置的刷屏物忽略表可整体关掉；

✨ 稀有度强调 — 原版四档配色（白 / 黄 / 青 / 紫）；装了稀有度核心（RarityCore）会自动换成它的七档与玩家自定义色，并追加高稀有卡的入场扫光与按档阶梯的微光；

🆕 NEW 角标 — 这一局头一次见到的物品亮一下；

🧍 只弹你的 — 信号按拾取者过滤：别的玩家开箱、僵尸捡装备都不会弹到你屏幕上；

📐 位置与堆叠 — 默认落在快捷栏右侧那条带里、右缘对齐；锚点可拖、卡片可镜像（竖条搬到最右）、间距可调、缩放可自动（放不下才缩，下限 60%）或手动（50%~200%）；

🚦 满了先排队 — 同屏上限满了不顶掉旧卡，而是先排队；屏满队满之后再并成一张「还有 N 项」的溢出卡；

🎛️ 动画逐项可关 — 入场、合并脉冲、微光呼吸各自独立开关；入场与退场各有多种形态（滑出 / 拉幕，淡出 / 火车退回 / 拉幕收拢）；

🎨 卡面是数据 — 配色、圆角、描边、内边距、动画时长都在主题 JSON 里，改一个文件、一秒内生效，不用重启；

⚙️ 配置界面 — 按 K 打开：分页、可滚、悬停有说明，预览走真卡的画笔并重播整条时间线，拨任何时长键立刻看得见。

[h2=兼容性]

[h2=配置]

建议直接按 K 在界面里改 —— 界面显示的是生效值，改完立刻写盘。配置文件是 config/pickupcard-client.toml，常改的几项：

notice.holdMs| 4000| 一张卡停留多久（毫秒），从最近一次刷新算起；

notice.exitMs| 480| 退场动画时长；0 = 直接消失；

merge.mode| SAME_NBT| 合并粒度四档；

layout.maxOnScreen| 5| 同屏最多几张；

layout.queueSize| 9| 排队上限；0 = 不排队；

layout.scalePercent| 0| 0 = 自动（放不下才缩，下限 60%）；手动 50~200；

layout.align| RIGHT| 左缘对齐 / 右缘对齐；

layout.mirrorCard| false| 镜像卡片：竖条搬到最右缘，动画方向一起翻；

count.format| PLUS| +64 / ×64 / 64 / +1.2K；

废弃键 stickTo 与 leftEdge 读进来会被忽略（由 anchorX / anchorY 取代）。卡面外观不在 TOML 里 —— 它在主题 JSON 里，见上面「卡面是数据」那条。

[h2=已知限制]

目前只有 1.20.1 Forge 在产（1.21.1 的三个目标在仓库里显式记为未实现）；

静音名单只影响强调，不压制原版拾取音；

guiScale 拉到最大（画布 320×180）时英文界面标签会缩得偏小 —— 不重叠，但不好读；

没有服务端组件，所以拿不到只有服务端知道的信息：物品改名与 NBT 走的是「实体移除之前捞真身」这条路，绝大多数情况够用。

[h1=常见问题]

需要装到服务器上吗？ — 不需要 —— 没有服务端组件；任何服务器都能用，包括原版服与别人的整合包服；

别人捡东西我会看到卡吗？ — 不会，只有你自己的拾取会弹卡；

我捡了一整组，为什么只弹一张？ — 那是合并；想每次都单开一张，把 merge.mode 改成 NEVER；

改了 TOML 没反应？ — 先确认没有旧键残留（stickTo / leftEdge / merge.enabled / merge.windowMs 都已废弃并被忽略）；改外观项要去主题 JSON，不在 TOML 里；

卡一张都不弹？ — 依次看：总开关 enabled、过滤页的黑名单、同屏与排队上限是否被占满；

配置界面打不开？ — 键位是 K（可在原版控制里改）；若与别的模组冲突，改用 TOML 或换键。
