[h1=概述]

拾卡（Pickup Card）把你捡到的每一样东西变成 HUD 角上的一张玻璃拟态卡片：物品图标、名字与本次进账数量，稀有度决定强调色。连捡同一样东西不会刷屏 —— 它并进同一张卡，数字从旧值往上滚。

卡面由 [NanoVG](https://github.com/memononen/nanovg) 矢量自绘 —— 不依赖原版提示纹理，也不用另装渲染库。**纯客户端**：把 jar 丢进 `.minecraft/mods/` 就行，服务端什么都不用装，也不需要其他 mod。

[h2=主要功能]

🃏 物品与经验都有卡 — 稀有度竖条、物品图标、名字与本次进账数量；经验卡用下界之星图标与独立绿色；

➕ 合并 — 四档：从「同名同 NBT」到「从不合并」；合并时整张卡脉冲一下，数字从旧值往上滚；

🔇 过滤三表 — 黑名单 / 白名单 / 静音名单；规则支持 `minecraft:stone`、`#forge:ores`、`@somebotania`，另有可整体关掉的刷屏物忽略表；

🌈 稀有度强调 — 竖条与数量同色，用原版四档色；装了 RarityCore 就换成它的七档与你的自定义色，高档卡另加入场扫光与按档微光；

🆕 NEW 角标 — 这一局头一次见到的物品亮一下（刻意不落盘：换个世界就重置）；

🧍 只弹你的 — 别的玩家开箱、僵尸捡装备都不会弹到你屏幕上；

📐 位置与堆叠 — 锚点可拖、默认右缘对齐；最新的卡贴着物品栏上缘出现、把旧的向上顶；镜像、间距、缩放（自动下限 60%，或手动 50%~200%）都随你；

🚦 排队而不是丢弃 — 同屏满了先排队；队列也满了，就并成一张「还有 N 项」的溢出卡；

🎛️ 动画逐项可关 — 入场、合并脉冲、微光呼吸各有开关，入场与退场各有多种形态；

🎨 卡面是数据 — 配色、圆角、描边、内边距与时长都在 `assets/pickupcard/styles/*.json` 里；资源包覆盖即可，一秒内生效；

⚙️ 配置界面 — 按 **K**：分页、可滚、悬停有说明，预览会重播整条时间线；

⚡ 帧上很轻 — 5 张卡稳态约 0.9ms；进世界后第一张卡那帧从 42ms 降到 1.6ms。

[h2=配置]

**游戏内（推荐）** — 按 **K**；界面显示的是生效值，改完立刻写盘；

**文件** — `config/pickupcard-client.toml`；废弃键 `stickTo`、`leftEdge`、`merge.enabled`、`merge.windowMs` 会被忽略；

**常改的几项** — `notice.holdMs` (4000)、`notice.exitMs` (480；`0` = 无退场)、`merge.mode` (`SAME_NBT`)、`layout.maxOnScreen` (5)、`layout.queueSize` (9；`0` = 不排队)、`layout.scalePercent` (`0` = 自动)、`layout.align` (`RIGHT`)、`layout.mirrorCard` (off)、`layout.anchorX` / `anchorY` (`-1` = 自动)、`count.format` (`PLUS` / `X_PREFIX` / `PLAIN` / `ABBREVIATED`)。

[h2=兼容性]

Minecraft 1.20.1 + Forge 47.4.x — ✅ 首发目标，实测在跑；

服务端不装本 mod — ✅ 全部功能可用（纯客户端）；

与 UI Deck 同装 — ✅ NanoVG 走 JarJar 嵌套，无包冲突；

RarityCore — 🟡 可选；没装则回退原版四档；

Minecraft 1.21.1（Fabric / NeoForge / Forge） — ❌ 未实现；

Minecraft 1.20.1 Fabric / NeoForge — ❌ 未实现。

[h2=已知限制]

**只有 1.20.1 Forge 在产** — 1.21.1 的三个目标在 `versions/targets.json` 里记为未实现；

**静音名单不压制声音** — 卡照样弹，只是不高亮；

**窄画布上英文标签会缩字** — guiScale 最大（画布 320×180）时变小，但不重叠；

**很长的过滤规则要靠悬停看全文** — 规则行只显示一行，全文在下面的说明条里；

**没有服务端组件** — 物品改名与 NBT 走的是「实体移除之前捞真身」，绝大多数情况够用。

[h1=常见问题]

**需要装服务端吗？** 不需要 —— 没有服务端组件。任何服务器都能用，原版服与整合包服都行。

**别人捡东西我会看到卡吗？** 不会。只有你自己的拾取会弹卡。

**捡了一整组，怎么只有一张卡？** 那是合并；想每次都单开一张，把 `merge.mode` 改成 `NEVER`。

**改了 TOML 没反应。** 先看有没有废弃键残留；外观项压根不在 TOML 里。

**一张卡都不弹？** 依次看：总开关 `enabled`、过滤页的黑名单、同屏与排队上限是否占满。

**配置界面打不开？** 键位是 **K**（可在原版控制里改）；被别的模组占了就用 TOML 或换个键。

**可以放进整合包吗？** 可以 —— 代码是 MIT，不需要额外授权；重新分发 jar 时请保留第三方声明。
