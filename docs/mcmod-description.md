拾卡（Pickup Card）把你捡到的每一样东西变成 HUD 右下角的一张玻璃拟态卡片：物品图标、名字、本次进账数量，稀有度决定强调色。捡东西不再只有「叮」一声和物品栏里多出来的一格。

纯客户端模组：服务端不用装，任何服务器与任何整合包都能用。零必需前置 —— 卡面全部由 NanoVG 矢量自绘，不依赖原版提示纹理，也不依赖任何渲染前置。

卡面是数据不是代码：配色、圆角、描边、内边距、动画时长都在主题 JSON 里，资源包覆盖即可改，不用重启。

[h1=主要功能]

🃏 卡片提示 — 拾取物品或经验时弹出一张卡：竖条（稀有度色）+ 物品图标 + 名字 + 数量；经验卡用下界之星图标与独立绿色，与物品卡共用合并与过滤规则；

➕ 合并 — 四档粒度（同名同 NBT / 同名就并 / 改名不并 / 从不合并）；合并瞬间整张卡脉冲一下，数字从旧值滚到新值；

🔇 过滤三表 — 黑名单（不弹）、白名单（永远弹并强调）、静音名单（弹，但不强调）；规则支持 minecraft:stone / #forge:ores / @somebotania 三种写法，内置的刷屏物忽略表可整体关掉；

🆕 NEW 角标 — 这一局头一次见到的物品亮一下（刻意不落盘：换世界就重置）；

✨ 稀有度强调 — 原版四档配色（白 / 黄 / 青 / 紫）；装了稀有度核心（RarityCore）会自动换成它的七档与玩家自定义色，并追加高稀有卡的入场扫光与按档阶梯的微光；

🧍 只弹你的 — 信号源头按拾取者过滤：别的玩家开箱、僵尸捡装备都不会弹到你屏幕上；

📐 位置与堆叠 — 默认落在快捷栏右侧那条带里、右缘对齐，最新的卡贴着物品栏上缘出现、旧的向上顶；锚点可拖、卡片可镜像（竖条搬到最右）、间距可调、缩放可自动（放不下才缩，下限 60%）或手动（50%~200%）；

🚦 满了先排队 — 同屏上限满了不顶掉旧卡，而是先排队；屏满队满之后再并成一张「还有 N 项」的溢出卡；

🎛️ 动画逐项可关 — 入场、合并脉冲、微光呼吸各自独立开关；入场与退场各有多种形态（滑出 / 拉幕，淡出 / 火车退回 / 拉幕收拢）；

🎨 卡面是数据 — 从 jar 里取出 assets/pickupcard/styles/default.json，放进资源包同路径覆盖，配色、圆角、描边、内边距、动画时长就是你的，一秒内生效、不用重启；

⚙️ 配置界面 — 按 K 打开：分页、可滚、悬停有说明，预览走真卡的画笔并重播整条时间线，每页都有「恢复本页默认」；

⚡ 帧上很轻 — 5 张卡稳态绘制约 0.9ms；进世界后分 7 帧预热，第一张卡那帧从 42ms 降到 1.6ms，另有硬预算护栏会在超线时记一条日志。

[h1=使用方法]

1. 进世界，捡起任意物品 —— 快捷栏旁出现一张卡。
2. 按 K 打开配置界面：左边选页、右边改值，`位置与堆叠` 页可以直接拖拽调整落点。
3. 觉得哪样东西太吵，在过滤页把它拉进黑名单；想让它永远显眼就拉进白名单。
4. 想每次都单开一张卡，把 `merge.mode` 改成 `NEVER`。

[h1=前置与安装]

需要 Minecraft 1.20.1 + Forge 47.4.x，无其他必需前置。把 jar 丢进 mods/ 即可，服务端不用装任何东西。

可选联动 RarityCore：装了就用它的七档稀有度与自定义配色，没装回退原版四档。与 UI Deck 同装也没问题 —— NanoVG 走 JarJar 嵌套供应，两个 mod 不会抢同一个包。

[h1=配置文件]

建议直接按 K 在界面里改 —— 界面显示的是生效值，改完立刻写盘。配置文件是 `config/pickupcard-client.toml`。常改的几项：

- `notice.holdMs` 4000 —— 一张卡停留多久（毫秒），从最近一次刷新算起
- `notice.exitMs` 480 —— 退场动画时长；0 = 直接消失
- `merge.mode` SAME_NBT —— 合并粒度四档
- `layout.maxOnScreen` 5 / `layout.queueSize` 9 —— 同屏上限与排队上限（0 = 不排队）
- `layout.scalePercent` 0 —— 0 = 自动（放不下才缩，下限 60%）；手动 50~200
- `layout.align` RIGHT / `layout.mirrorCard` false —— 对齐与镜像
- `layout.anchorX` / `anchorY` -1 —— 落点（屏幕比例），-1 = 自动，推荐在界面里拖
- `count.format` PLUS —— `+64` / `×64` / `64` / `+1.2K`

废弃键 `stickTo` 与 `leftEdge` 读进来会被忽略（由 `anchorX` / `anchorY` 取代）。**卡面外观不在 TOML 里**，见上面「卡面是数据」那条。

[h1=已知限制]

1. 目前只有 1.20.1 Forge 这一个目标在产（1.21.1 的三个目标在仓库里显式记为未实现）。
2. 静音名单只影响强调，**不压制原版拾取音** —— 卡照样弹，只是不高亮（1.20.1 的原版拾取音在不可取消的注入点上）。
3. guiScale 拉到最大（画布 320×180）时英文界面标签会缩得偏小 —— 不重叠，但不好读。
4. 很长的过滤规则要靠悬停看全文：规则行只显示一行，全文在那行底部的说明条里。
5. 没有服务端组件，所以拿不到只有服务端知道的信息 —— 物品改名与 NBT 走的是「实体移除之前捞真身」这条路，绝大多数情况够用。

[h1=常见问题]

**需要装到服务器上吗？** 不需要，装了也没有服务端组件。任何服务器都能用，包括原版服与别人的整合包服。

**别人捡东西我会看到卡吗？** 不会。只有你自己的拾取会弹卡。

**我捡了一整组，为什么只弹一张？** 那是合并。想每次都单开一张，把 `merge.mode` 改成 `NEVER`。

**改了 TOML 没反应？** 先确认没有旧键残留（`stickTo` / `leftEdge` / `merge.enabled` / `merge.windowMs` 都已废弃并被忽略）；改外观项要去主题 JSON，不在 TOML 里。

**卡一张都不弹？** 依次看：总开关 `enabled`、过滤页的黑名单、同屏与排队上限是否被占满。

**配置界面打不开？** 键位是 K（可在原版控制里改）。若与别的模组冲突，改用 TOML 或换键。

**可以放进整合包吗？** 可以。代码是 MIT，不需要额外授权；重新分发 jar 时请保留仓库里的第三方声明。
